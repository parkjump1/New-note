# 하루 목표 기록장

매일 아침의 다짐을 기록하고, 생각의 흐름을 분석하는 앱입니다.
기록은 각자의 기기(브라우저)에만 저장되어 다른 사람에게 보이지 않습니다.

## 설치하는 방법
Chrome에서 앱 주소 열기 → 오른쪽 위 ⋮ → "앱 설치" (또는 "홈 화면에 추가")
아이폰은 Safari에서 열기 → 공유 버튼 → "홈 화면에 추가"

## 기능
- 오늘: 아침 목표, 저녁 한 줄 회고, 지난주·한 달 전 다짐 돌아보기
- 기록: 전체 기록 검색, 백업 파일 저장/불러오기
- 분석: 주제 비중, 다짐의 방향, 요일 패턴, 자주 쓰는 말, Claude 분석(복사→붙여넣기), 리포트 공유
