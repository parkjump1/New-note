# ☀️ 하루 목표 기록장

매일 아침 "오늘 어떤 하루를 만들고 싶은지" 한두 문장으로 적는 앱이에요. 기록이 쌓이면 내가 자주 다짐하는 마음, 요일별 패턴, 생각이 어떻게 바뀌어 가는지를 분석해서 보여줘요.

👉 **주소: https://parkjump1.github.io/New-note/**

## 📲 설치 방법
- **안드로이드:** Chrome에서 주소 열기 → 오른쪽 위 ⋮ → "앱 설치"(또는 "홈 화면에 추가")
- **아이폰:** Safari에서 주소 열기 → 아래 공유 버튼 → "홈 화면에 추가"

## ✍️ 사용법
- **오늘 탭:** 아침에 목표 한 줄, 퇴근 전에 달성도(1~5)와 회고 세 칸 — 잘 된 것 · 흔들린 순간 · 내일 가져갈 것 (선택)
- **분석 탭:** 3일 이상 기록하면 나의 패턴이 보여요
- **Claude 분석:** '기록 복사하기' → Claude 앱에 붙여넣기 → 받은 답을 다시 붙여넣기
- **리포트 공유:** '공유·저장' 버튼으로 내 리포트를 파일로 보낼 수 있어요

## 🔒 꼭 알아두세요
- 기록은 각자 휴대폰 안에만 저장돼요. 로그인이 없고, 다른 사람은 볼 수 없어요.
- 앱을 지우거나 브라우저 데이터를 지우면 기록도 사라져요. 기록 탭 맨 아래 '백업 파일 저장'을 가끔 눌러 두세요!
